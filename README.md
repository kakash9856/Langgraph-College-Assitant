# LangGraph College Assistant

An AI-powered College Assistant built using LangGraph, RAG, FAISS, Hugging Face Embeddings, Groq LLM, and Streamlit.

## Features
- Academic information retrieval
- Fee-related queries
- General question answering
- PDF-based RAG system
- Interactive Streamlit chat interface
- Programme-specific responses

## Tech Stack
- Python
- LangGraph
- LangChain
- FAISS
- Hugging Face Embeddings
- Groq LLM
- Streamlit
